# Exact pins, not ranges: a submission judged in October must install the same tree the
# demo was recorded against. `scripts/check_versions.py` holds every document that names a
# version to what is pinned here, and `--check-upstream` catches a pin that has gone stale.

# The agent framework, with the extras that carry the Fortified Enterprise Fleet pillars:
#   a2a             -> a2a-sdk: AgentCard, Task, TaskState — the inter-agent contract
#   agent-identity  -> credential brokering, the principal Agent Gateway authorises on
#   gcp             -> aiplatform[agent-engines], bigquery, pubsub, secret-manager,
#                      and the OpenTelemetry GCP exporters
#   otel-gcp        -> Cloud Trace / Cloud Logging exporters for `--trace_to_cloud`
#   mcp, tools      -> tool surface; Agent Registry catalogs MCP servers alongside agents
#   eval            -> `adk eval`, the reasoning-chain evidence the track asks for
#
# NOT installed, deliberately: the `antigravity` extra. `google-antigravity` ships protobuf 7
# gencode while a2a-sdk and google-cloud-aiplatform both pin protobuf<7, so it cannot coexist
# with the Gateway and Runtime pillars. See docs/adr/007-adk-as-the-agent-framework.md.
google-adk[a2a,agent-identity,gcp,otel-gcp,mcp,tools,eval]==2.7.1

# Pinned explicitly because the ADK extras above do not carry them, and the versions a
# document may name must resolve to something.
