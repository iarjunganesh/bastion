# Research documents

Working documents for the Bastion technical report. They bound what the report and the public
pages may claim; the report sources are in [`report/`](../../report/README.md), released as tag `report-2026-11`.

| Document | Purpose |
|---|---|
| [Report plan](report-plan.md) | The single sequence for the report and its GCP evidence runs |
| [Claim matrix](claim-matrix.md) | Implemented, tested, deployed and observed status of each claim, with safe wording |
| [Remediation ledger](remediation-ledger.md) | P0/P1 closure, narrowed observations and remaining limitations |
| [Observation backlog](observation-backlog.md) | Dated capture status, defect history and unclaimed behaviours |

Evidence records are in [assets/evidence/](../../assets/README.md). Hackathon-era planning is
archived in [archive/hackathon-2026/](../../archive/hackathon-2026/README.md).
